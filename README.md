# orilurie.github.io

## חתחתול אונליין 🐱🐭

משחק הקלפים חתחתול לשחק עם חברים (2–6 שחקנים): `hathatul/`

- אתר סטטי בלי שרת. השחקנים מתחברים ישירות דרך WebRTC (PeerJS), והמארח/ת מריץ/ה את המשחק בדפדפן.
- `?local=1` מריץ את המשחק בין לשוניות באותו דפדפן (לבדיקות).
- `game.js` חוקי חתחתול · `quartets.js` + `quartets-ui.js` רביעיות · `util.js` סדר תורות הוגן · `net.js` תקשורת · `app.js` ממשק וניהול החדר.
- במסך הפתיחה בוחרים משחק (חתחתול / רביעיות). החדר נוצר למשחק שנבחר, ומי שמצטרף לפי קוד נכנס אוטומטית לאותו משחק.
