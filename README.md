# orilurie.github.io

## חתחתול אונליין 🐱🐭

משחק הקלפים חתחתול לשחק עם חברים (2–6 שחקנים): `hathatul/`

- אתר סטטי בלי שרת. השחקנים מתחברים ישירות דרך WebRTC (PeerJS), והמארח/ת מריץ/ה את המשחק בדפדפן.
- `?local=1` מריץ את המשחק בין לשוניות באותו דפדפן (לבדיקות).
- `game.js` חוקי חתחתול · `quartets.js` + `quartets-ui.js` רביעיות · `util.js` סדר תורות הוגן · `imposter.js` + `imposter-ui.js` + `imposter-words.js` המתחזה (1000 מילים, 5 רמזים לכל מילה) · `battleship.js` + `battleship-ui.js` + `battleship-3d.js` צוללות בתלת־ממד (three.js ב-`vendor/three`, רישיון MIT) · `net.js` תקשורת · `app.js` ממשק וניהול החדר.
- במסך הפתיחה בוחרים משחק (חתחתול / רביעיות / צוללות / המתחזה). החדר נוצר למשחק שנבחר, ומי שמצטרף לפי קוד נכנס אוטומטית לאותו משחק.

## התזונה שלי 🥗

אפליקציית מעקב תזונה אישית: `nutrition/`

- מזינים את התפריט מהמאמן (לשונית "התפריט"), ובמסך "היום" מסמנים מה אכלת. יש גם מעקב קלוריות, חלבון/פחמימה/שומן, מים ומשקל.
- הנתונים נשמרים בדפדפן (localStorage), ואחרי התחברות גם בענן: Supabase של אפליקציית הבית (אותם משתמשים), טבלאות `nutrition_state` ו-`nutrition_days` עם RLS וסנכרון realtime. הטבלאות נוצרות מ-`supabase.sql`. אפשר גם להמשיך בלי חשבון.
- שיתוף לקריאה בלבד עם מאמן (`nutrition_shares`), הודעות מהמאמן שקופצות בכניסה (`nutrition_messages`), ותמונות התקדמות ב-Storage (`nutrition-photos`). נוצרים מ-`supabase-sharing.sql`.
- זיהוי אוכל מתמונה: פונקציית Supabase `nutrition-food-photo` (בריפו home) ששולחת ל-Gemini. המפתח שמור כסוד `GEMINI_API_KEY` ב-Supabase.
- גיבוי ושחזור דרך קובץ JSON במסך ההגדרות.
- `foods.js` מאגר מזונות בסיסי (ל-100 גרם) · `store.js` נתונים ושמירה · `cloud.js` התחברות וסנכרון · `app.js` ממשק.
